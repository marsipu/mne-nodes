# Report a problem

When something fails, a dialog shows the error. Errors of a running pipeline
appear in the console.

![The error dialog with a traceback and the report buttons](../_static/screenshots/linux/error-dialog.png)

| Button | Effect |
| --- | --- |
| **Copy traceback** | Copies the full error text as it is, without redaction |
| **Open GitHub issue...** | Prepares a redacted report that you can review and edit |

Check the box to add anonymized system information, loaded plugins, and a
dataset summary to the report.

The report is copied to your clipboard and a draft issue opens in your
browser. Nothing is sent until you submit the issue yourself, so remove any
private details first.
