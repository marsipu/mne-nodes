# User guide

In mne-nodes, processing functions are nodes that you connect into a pipeline.
The functions come from plugins, and a finished pipeline can be exported as a
plain Python script.

| I want to ... | Read |
| --- | --- |
| Build and run my first pipeline | [Build and run a pipeline](pipelines.md) |
| Use my own data or the sample data | [Datasets and recordings](data.md) |
| Keep results on disk | [Save results](derivatives.md) |
| Get more processing functions | [Plugins](plugins.md) |
| Turn my own Python function into a node | [Create your own nodes](function_importer.md) |
| Pass a pipeline or plugin to others | [Share pipelines and plugins](sharing.md) |
| Work with MRI data | [FreeSurfer](freesurfer.md) and [Coregistration](coregistration.md) |
| Change the look of the application | [Settings](settings.md) |
| Report a bug | [Report a problem](errors.md) |
