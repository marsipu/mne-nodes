Try the sample dataset
======================

Choose **BIDS > Add Sample BIDS** or start the welcome tour. The sample data
may require a large download. It includes a MEG recording, an MRI, a FreeSurfer
reconstruction, and a head-to-MRI transformation.

Select the MEG recording on the input node to use its associated ``anat``,
``subject``, and ``trans`` outputs. Re-importing preserves existing sample
anatomy, reconstructions, and transformations.
